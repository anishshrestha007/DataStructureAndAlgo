Good to know

  • Every file also runs in Node: use Copy Node command on a file and paste it into a terminal.
  • ES modules (import/export), web workers and the Source tab need the folder served over http, for example npx serve or VS Code Live Server. Opening index.html straight from disk works for everything else.
  • Added or moved a file? Run node playground/generate-manifest.js to refresh this list.
